# ИС «Аренда» — сайт агентства по аренде недвижимости (г. Уфа)

Учебная практика ПМ.05, МДК 05.02 «Разработка кода информационных систем»,
задания 2–4. Сайт на Python + Flask, база данных SQLite.

## Что реализовано

- **Задание 2 — модуль заявки на подбор жилья:** выбор объекта, проверка ФИО,
  телефона и почты, поиск арендатора без дублей, номер заявки `ЗАЯ-2026-0001`,
  сохранение в базу, защита от повторной заявки.
- **Задание 3 — работа с базой данных:** 8 таблиц, сохранение, просмотр,
  изменение, удаление и поиск записей (объекты, заявки, собственники,
  сохранённые поиски), миграция существующей базы без потери данных.
- **Задание 4 — интерфейс:** страницы по макетам 1-го модуля, каталог с
  фильтрами, форма заявки, проверка статуса, учёт объектов, кабинет риелтора,
  мобильная версия.

## Запуск

```bash
python -m pip install flask
python app.py
```

Сайт откроется по адресу <http://127.0.0.1:8090/>.
Вход в кабинет риелтора: логин `kapustin`, пароль `ufa2026`.

Проверка модуля (25 автоматических проверок на копии базы):

```bash
python demo_checks.py
```

## Структура

| Файл | Назначение |
|---|---|
| `app.py` | Маршруты Flask |
| `applications.py` | Модуль заявок |
| `catalog.py` | Учёт объектов и собственников |
| `db.py` | Подключение, создание и миграция базы |
| `schema.sql` | Схема базы и справочники |
| `ufa_arenda.db` | База данных SQLite |
| `templates/` | Шаблоны страниц |
| `static/style.css` | Стили |
| `demo_checks.py` | Автоматические проверки |
| `dbviewer.html`, `refresh_db.py` | Просмотр базы в браузере |
| `Запросы к базе.command` | Готовые SQL-запросы двойным щелчком |
| `original_snapshot/` | Исходная версия проекта до доработки |
| `Отчеты/` | Отчёты по заданиям, скриншоты, результаты проверок |

Для просмотра базы как в phpMyAdmin используйте
`Отчеты/Админка базы/Открыть админку базы.command`.

## Дефекты для тестирования (МДК 05.03)

1. `normalize_phone` принимает номера, начинающиеся с нуля.
2. После отправки форм flash-сообщения не выводятся.
3. На кнопке формы заявки текст «Отправить» вместо «Отправить заявку».
