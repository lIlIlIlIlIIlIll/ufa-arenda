Учебная практика ПМ.05, МДК 05.02 «Разработка кода информационных систем»,
задания 2–4. Сайт на Python + Flask, база данных SQLite.

## Что реализовано

- **Задание 2 — модуль заявки на подбор жилья:** выбор объекта, проверка ФИО,
  телефона и почты, поиск арендатора без дублей, номер заявки `ЗАЯ-2026-0001`,
  сохранение в базу, защита от повторной заявки.
- **Задание 3 — работа с базой данных:** 8 таблиц, сохранение, просмотр,
  изменение, удаление и поиск записей (объекты, заявки, собственники,
  сохранённые поиски), миграция существующей базы без потери данных.
- **Задание 4 — интерфейс:** страницы по макетам 1-го модуля, каталог с
  фильтрами, форма заявки, проверка статуса, учёт объектов, кабинет риелтора,
  мобильная версия.

## Запуск

```bash
python -m pip install flask
python app.py
```

Сайт откроется по адресу <http://127.0.0.1:8090/>.
Вход в кабинет риелтора: логин `kapustin`, пароль `ufa2026`.

Проверка модуля (25 автоматических проверок на копии базы):

```bash
python demo_checks.py
```

## Задание 5 — безопасность

- Гость видит каталог, заявку и «только просмотр» объектов. Добавление, изменение,
  удаление объектов, собственники и работа с заявками — только после входа
  (декоратор `@login_required`).
- Проверка всех данных форм на сервере: ФИО, телефон, почта, числа, длина текста.
- Вход блокируется на 10 минут после 5 неудачных попыток.
- После входа переход разрешён только на адрес своего сайта (проверка `next`).
- SQL-запросы только с параметрами; поиск заявки по телефону — по цифрам номера.
- Проверка: `python demo_security.py` — 30 проверок.

## Как пользоваться

1. Открыть <http://127.0.0.1:8090/> — каталог.
2. «Оставить заявку» → выбрать объект → заполнить → «Отправить» → сохранить номер заявки.
3. «Мои заявки» — проверить статус по номеру или телефону.
4. «Войти» (`kapustin` / `ufa2026`) → «Заявки в работе» → открыть заявку → перевести статус:
   «В работе» → «Связались» → «Подобран» → «Закрыта».
5. Вкладка «Объекты» — добавить, изменить, удалить объект (удаление объекта с заявками запрещено).
