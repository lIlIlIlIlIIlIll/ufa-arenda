# Админка базы

Чтобы открыть админку базы (аналог phpMyAdmin):

1. Скопируйте рабочую базу `ufa_arenda.db` из корня проекта в `Отчеты/Админка базы/data/site.db`.
2. Двойной щелчок по файлу `Открыть админку базы.command` в папке `Админка базы`.
3. Пароль: `arenda`.

Админка работает с копией базы каждые 2 секунды — удобно для просмотра.
